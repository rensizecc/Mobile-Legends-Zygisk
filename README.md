### 🎯 What is rensize.cc?

**rensize.cc** is a powerful visual enhancement module for Mobile Legends that provides real-time tactical information, helping you make better decisions in battle.

## ✨ Features

### 🔍 **ESP System**
```
📦 Smart Box ESP         → Multiple styles (Normal, Cornered, Rounded)
🎯 Off-Screen Indicators → Hero icons with HP rings at screen edges  
👣 Animated Trails       → Glowing footprints showing enemy paths
⏱️ Skill Cooldowns       → Real-time tracking of all enemy abilities
📏 Distance Display      → Precise range calculation
🤖 Bot Detection         → Distinguish AI from real players
🖼️ Hero Icons            → High-quality portraits
```

### 📷 **Camera Control**
```
🎥 Dynamic Height        → Adjust camera distance for better view
🔄 Smooth Transitions    → No stuttering or glitches
✨ Game-Accurate Values  → Uses real game depth system
```

### ⚡ **Auto Features**
```
🎯 Auto Retribution      → Smart jungle objective timing
📊 Priority System       → Lord > Turtle > Buffs (customizable)
📡 Range Detection       → Set activation radius
```

### 🎨 **Modern Interface**
```
📱 iOS-Style Menu        → Swipe-up pill bar opener
🎨 Full Customization    → RGB color picker for all elements
🔔 Toast Notifications   → Non-intrusive feedback
⌨️ Virtual Keyboard      → Built-in text input
```
